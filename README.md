# JustAIAgent (JAA)

**Just an agent. Your Linux machine. Your control.**

精简、封闭的 Linux 原生本地 AI Agent（简称 **JAA**）。Rust 单进程服务内嵌 React 网页，支持桌面与移动端通过浏览器远程控制本机；专注 Responses 协议，不绑定特定模型厂商。

## 核心特性

- **Linux 原生单二进制**：Rust 后端 + 内嵌 `web/dist` 前端资源，部署无需 Node.js 运行时。
- **固定 14 个内置工具**：`read`、`write`、`edit`、`glob`、`grep`、`bash`、`job`、`subagent`、`read_image`、`web_search`、`web_fetch`、`ask_user`、`goal`、`computer`（支持独立浏览器与 KDE Wayland 桌面）。
- **多引擎免费深度网络搜索**：`web_search` 支持全网聚合（`auto`）与深度搜索（`depth="deep"`），并行整合 DuckDuckGo、Bing、Wikipedia、GitHub、arXiv、HackerNews、StackOverflow，以及 Brave Search / SearXNG。
- **模型质量与 Linux 网络诊断**：支持每模型 Responses 质量检查、上游自报模型与响应头比对、生成速度（tok/s）与缓存命中观测，以及基于 Linux `curl` / `traceroute` / `tracepath` / `mtr` 的连接阶段延迟、TLS 证书与路由跳数探测。
- **模型品牌头像识别**：对话界面根据模型名称自动匹配显示 Gemini、DeepSeek、GLM、GPT、Claude、Qwen、Grok 等官方图标。

  - 贡献者：Antigravity

## 产品边界

- 无插件、无 MCP、无动态工具、无用户脚本扩展、无交互式 CLI / TUI。
- 固定工具：`read`、`write`、`edit`、`glob`、`grep`、`bash`、`job`、`subagent`、`read_image`、`web_search`、`web_fetch`、`ask_user`、`goal`、`computer`。语义可选参数可省略或显式 null，真正必填和动作条件严格校验；strict 出站编码与运行时业务必填分开，原始参数仍原样回放。
- 默认使用**最高可用权限**：Bash 在进程本身是 root 时直接执行，否则检测免密 `sudo -n` 并使用 root 执行通道；没有该系统授权时明确报告当前用户，不虚报 root。协调器和图形会话可保持桌面用户身份，系统级文件/服务操作通过特权 Bash 完成。没有审批、沙箱和目录边界，cwd 不是安全边界。
- 内置一层 subagent，最多 4 个同时运行。子 agent 不能再次创建 agent。
- 上下文达到配置预算时，在工具完整结算的安全边界**自动压缩并继续当前任务**；也保留手动压缩。原始历史仍在明文会话日志中，摘要失败不会替换原上下文。
- 已提交上下文只追加；工具输出首次进入上下文前限长，后续不反复改写历史；不做缓存命中率面板，也不承诺中转站的缓存行为。
- 酒红明亮主题 / 电光青暗色主题；移动端布局与实时任务事件。

> 登录者可以让 AI 执行任意本机命令。因此 UI 密码是这台机器的远程控制凭据，而不仅是聊天登录密码。

## 构建

需要 Linux、Rust 稳定版（至少 1.88）、Node.js 22+（只用于构建网页）、npm，以及编译 SQLite/TLS 依赖所需的 C/C++ 构建工具、CMake。运行成品无需 Node.js。

```sh
cd web
npm ci
npm run build
cd ..
cargo build --release --locked
./target/release/justaiagent --workspace /path/to/project
```

默认打开 `http://127.0.0.1:4141`。先在本机设置至少 12 字节的密码，再配置模型。默认私有数据目录是 `~/.local/share/justaiagent`，可以使用 `--data-dir PATH` 或 `JUSTAI_DATA_DIR` 更改。数据库目录权限 0700、数据库 0600。

启动选项仅用于部署，不提供另一套 agent 命令行交互界面：

```text
--bind IP             默认 127.0.0.1
--port PORT           默认 4141
--workspace PATH      默认启动目录
--data-dir PATH       私有数据库和任务日志
--public-url URL      远程访问的精确 HTTPS origin
```

### 本次开发实例

已编译 Release 并在 `http://127.0.0.1:4141` 启动。使用项目内的私有数据目录 `.runtime/app`，预置用户授权的测试站点和模型，不包含验证用密码或测试会话。首次打开请自行设置访问密码。

重启并保留本次 GUI 配置：

```sh
./target/release/justaiagent --data-dir .runtime/app --workspace "$PWD"
```

运行数据被版本控制忽略，密钥未编译进可执行文件或网页。切换到默认数据目录会得到另一份独立配置。验证过程中临时使用了直连模式，可在 GUI 改为适合本机的代理。

### GUI 模型配置

设置中按 **站点 → API Key → 模型** 添加：

- 站点：名称、API base URL（通常以 `/v1` 结尾）。
- Key：名称、密钥。一个站点支持多个 Key；页面不读取已保存的密钥原文。
- 模型：显示名称、实际模型 ID、是否支持图片、最大输出 token、上下文窗口、可用思考等级与默认等级。
- 兼容项：固定缓存路由标识、严格工具 schema、推理状态回放、是否发送 `store:false`，以及独立的**省略 strict 标记**。固定路由默认开启；端点不支持 `prompt_cache_key` 时可关闭。只启用端点确实支持的能力。

**持续低缓存的兼容选项：** 设置 → 站点 → 所选模型 → 协议高级选项 → **省略 strict 标记**。部分 Responses 兼容端点在 `strict:true` 处理路径下无法复用长历史，已用约15.5万token真实历史的反向A/B/A复现：开启strict时只命中896，单独省略字段后约99.94%。此开关面向所有站点/模型，现按用户要求默认开启；新建模型或缺失此字段时都启用，显式设置为false仍可关闭。当前实例的已有模型也按本次授权启用；没有按模型名或站点名写死规则。

该选项只移除出站 `tools[*].strict` 字段，保留原schema、required/nullable、additionalProperties以及本地严格参数/执行校验。与“严格工具 schema”独立：若原严格schema已开，可保持开启，只省略标记；若原schema关闭，则先应用现有宽松wire投影，再省略标记。代价是端点不再按这个字段提供约束生成，模型可能多报参数错误，本地仍拒绝执行不合法调用。不是所有端点都受此问题影响，也不保证每次首请求命中；更改后工具前缀发生一次预期变化，后续需保持设置稳定。详见 [缓存对照与因果证据](CACHE_STRICT_CAUSALITY.md)。

保存采用配置版本冲突检测；另一设备修改后需要重新加载。空密钥输入表示保留同站点、同 Key、同端点的已存值；**更改站点地址必须重新输入 Key**，不会自动将旧凭据发送到新站点。

创建会话后也可以直接在聊天中切换站点 / Key / 模型 / 思考强度。思考强度支持继承模型默认、不发送或明确指定；不会因此改写全局模型模板。运行中修改在下一次模型请求边界生效，已发出的请求保持原快照。每条回复记录实际站点与模型，切换后不会改写历史作者。

会话和 subagent 只引用配置 ID；每次实际模型请求解析当前配置版本，Authorization 不缓存进长期客户端默认 Header。切换模型路由时建立协议兼容的新上下文投影：保留原始记录、可见消息及工具配对，不自动摘要；不把原供应商的加密推理或响应句柄发送给另一家。切换到纯文本模型时，旧图像在网络投影中用附件说明替代，原图仍在本地历史中。普通未切换的会话保持只追加的请求前缀。

不同模型与中转的实际能力、上下文、计费由供应商决定。声明支持图片并不会让不支持图片的模型获得视觉能力。

### 每模型中转质量检查

设置 → 站点 → Key → 选择模型 → **模型质量检查**。先展示检查计划与请求数，再由用户点击开始；打开、预览和刷新不调用供应商。默认14次合成短请求、每次输出cap256，不读取聊天历史、不执行模型工具，可取消、持久查看和导出JSON。

表格展示请求模型/返回自报、响应头/首事件/首token/总延迟、真实缓存读与输入比例、HTTP/Responses终态、服务端自报API/提供方/tier/请求标识、完整数值usage、答案/工具参数/原生拒绝。支持手工费率估算，缺失用量/费率明确未知，不伪造价格或底模身份证明。

指令测试包含Ignore、子代理身份、独立完成、继承历史、禁止再委派、最终报告、工具不可信、工作目录约束和中文等义对照共9类，可选重复成对运行；扩展缓存条件与256KiB大上下文默认关闭，选中后重新显示费用规模。完整说明见 [模型质量检查](MODEL_QUALITY_CHECKS.md)。

另有独立可选的**网络诊断**：只选网络时4项任务、0次模型请求，测DNS解析/IP、TCP/TLS/HTTP阶段、匿名HEAD三次延迟及抖动、HTTP版本/重定向/安全响应头、TLS证书可用字段和CDN候选证据。路由跳数需单独勾选，最多12跳/每跳1次/总5秒；代理配置下不绕过代理，无法确认的跳数/证书/CDN身份明确未知。结果可持久查看、取消和导出，不发送聊天历史或模型Key。完整说明见 [模型质量检查](MODEL_QUALITY_CHECKS.md)。

### 输入、图片粘贴与运行中消息

- 输入框直接接收浏览器 `paste` 事件：Ctrl+V 可粘贴文字或图片，也支持一次多图及图片/文字混合。Ctrl+Shift+V 会使用浏览器实际提供的剪贴板数据；如果浏览器把它定义为“仅纯文本”，程序不会假称能恢复被浏览器去掉的图片。
- 支持 PNG/JPEG/GIF/WebP，最多 8 张、每张 10 MiB，并检查整条请求约 24 MiB 的编码预算；纯文本模型会明确提示不支持图片。不读取后台剪贴板、不执行粘贴的 HTML，保留光标位置和中文输入法行为。
- 同一次 paste 的 items/files 双渠道按实际图像数据精确去重，文件名或时间不同也不会重复附加；不同内容、分两次故意粘贴同图或主动上传同图不会误删。不是模糊感知去重，不声称跨不同有损编码的近似照片一定能识别成同图。
- 点击草稿附件或历史用户图片可在页面内预览、多图左右切换、查看计数；关闭或 Esc 返回原焦点。只显示允许的栅格图片，不执行 HTML/SVG 脚本，不依赖 data URL 新标签页。
- AI 工作时输入框仍可发送；**所有新消息默认工具调用后交付**。发送后，在消息输入框按 **Esc**，会将最新一条已发送、尚未交付的消息提升为**强制介入**，仍使用同一个 UUID，不重新发送第二条正文。Esc 不发送草稿、不改变下一条草稿的默认模式；没有待送消息时无动作。
- 强制介入会终止尚未提交的模型生成；已开始的工具先安全结束，未开始的后续工具标记 NOT EXECUTED，再将新消息送入模型。已交付的消息再次 Esc 不会中断无关工作。输入法组合、图片预览、文件抽屉和其它弹窗的 Esc 保留各自关闭/取消语义。
- 立即介入不是操作系统强杀，不会撤销已经发生的写入或盲目重跑工具。手动/自动摘要到安全点后再交付；等待中的阻塞问题仍需通过问答面板回答。单独的停止按钮始终保留。
- 服务端消息以 client UUID 原子去重。运行中消息进入明文 SQLite FIFO 队列，接受时显示已排队，实际入模后更新送达状态；相同 UUID 重试不会重复插入、重复打断或重复执行。

### 断线与恢复

浏览器端待发送消息先写当前 origin/会话的 **IndexedDB 发件箱**，包括图片和固定 UUID；联网事件触发重试，页面重新打开也能恢复未发消息。认证或校验错误不会无限重试，可以手动重试/丢弃。没有把图片、认证 Cookie 或 API Key 写进 localStorage。普通消息在HTTP202或已持久化的SSE client-ID确认后移除发件箱，丢失202响应不会生成重复任务。Esc升级意图会额外持久保存，即使原after_call请求已在发送、接受确认丢失或消息已从发件箱清理，也会按同UUID确认升级，而不是丢掉介入意图；离线期间明确显示待联网，不假报已经中断。

网页断流不停止后端任务；SSE 在线后从最后 seq 立即重连、补放、去重。模型出站遇到真实连接/DNS/流传输问题时先做同代理/TLS策略的匿名 HEAD 连通探测：端点不可达则进入 `waiting_for_network`，按1/2/4/8/15秒间隔探测，恢复后从最后已提交边界继续。等待期间仍可插入消息或停止；新介入可唤醒旧生成，凭据/配置变化会重新解析新设置。

探测不携带模型 Key、Cookie 或生成 body，不自动换端点/代理/Key。认证、余额、JSON/工具协议错误不会伪装成断网无限等待；端点已可达但持续返回HTTP错误或坏流仍按正常有限重试停止。网络中断后的模型生成不是 token 级续传，可能重新收费；已执行工具不会跟着重跑。进程被杀或系统重启与临时断网不同：上下文/待发队列保留，但既有重启保护仍需用户显式继续，不悄悄恢复不确定的系统副作用。

### 子代理模型池

设置 → **子代理** 可添加最多 32 个预设。每个预设选择任意已配置站点、Key、模型，并指定独立思考强度：模型默认、不发送或支持列表中的等级。同一模型可以配置多个不同强度与名称的预设，例如“快速检索”和“深度审查”。预设只保存引用，不复制密钥。

AI 可调用 `subagent` 的 `models` 动作查看候选；创建时通过 `model_id` 指定**预设 ID**，不是自行填写供应商模型名。未指定、null 或 `inherit` 均沿用父会话模型与思考强度。不能绕过用户模型池选择未知模型。删除被引用的站点/Key/模型前，需要先更新或删除对应预设，界面会明确提示，不静默丢配置。

模型池只在首次使用或实际变更时追加到父会话上下文，不每轮重建工具枚举或系统前缀。已启动的子代理保留自己的模型绑定；更改预设只影响以后创建的子代理。卡片和回复标注实际站点、模型与强度。

跨模型/站点创建时，子代理获得完整可见历史与工具结果，但不接收父供应商的加密推理与原生响应句柄；纯文本模型获得旧图片的附件说明。父会话历史不改写。相同路由沿用原生前缀，父子缓存路由标识仍按主会话族保持稳定，实际不同模型自然有各自缓存。

Responses 兼容桥可能在最终 completed 重发不同 item.id。本程序以稳定 call_id、工具名、原始完整参数及顺序校验执行身份，不再把单纯 item.id 重发误判为乱序；仍拒绝截断、真实工具错配和未完成调用。已使用用户配置的 DeepSeek 子代理完成隔离读文件往返验证。详细机制与边界见 [Responses 终态兼容修复](RESPONSES_COMPATIBILITY.md)。

## 代理和网络

三个明确模式：

1. **继承环境代理**：读取当前服务进程的 `https_proxy` / `HTTPS_PROXY`、`http_proxy` / `HTTP_PROXY`、`all_proxy` / `ALL_PROXY`，小写优先；协议专用变量优先于 ALL。排除规则使用显式 `no_proxy`，否则使用环境 `no_proxy` / `NO_PROXY`。CGI 环境中忽略大写 HTTP_PROXY。
2. **手动代理**：指定 HTTP(S) / SOCKS5 地址；`socks5h` 使用代理端 DNS。排除规则必须显式配置。
3. **直连**：关闭 HTTP 客户端的隐式代理发现。

指定代理失败不会自动回退直连。GNOME/KDE/PAC 不属于环境代理，第一版不自动读取它们；请手动配置。TUN 和系统路由由操作系统负责。

模型出站固定 HTTP/1.1、rustls TLS、系统证书验证、无自动重定向、无 Cookie、无 HTTP 层隐藏重试。应用统一控制连接 / 响应头 / 流空闲 / 总期限、有限退避和取消。不要用禁用证书校验来修复网络问题。

完整响应成功终结、工具 item 完整、参数严格校验、执行意图持久化之后才执行工具。流中断或 token 截断不是成功。生成重试不是 token 级续传，可能再次收费。凭据失败不无限重试，也不会回退到旧 Key。

**bash 子进程是独立程序，不等于模型 HTTP 客户端。** 程序清洁传入环境，不自动把模型凭据传给 shell。外部工具的代理行为由其配置决定，强制整机代理需要系统 TUN/路由。

## 远程手机 / 电脑访问

### 推荐：HTTPS 穿透到回环端口

1. **先不带 `--public-url` 在本机初始化密码。** 未初始化时程序拒绝开启远程模式。
2. 让可信的 HTTPS 隧道 / 反向代理转发到 `127.0.0.1:4141`。
3. 使用精确公开域名启动：

```sh
./target/release/justaiagent \
  --workspace /path/to/project \
  --public-url https://agent.example.com
```

4. 手机打开该 HTTPS 地址，使用 UI 密码登录。模型请求和文件操作仍在服务器电脑执行。

直接局域网也需要 HTTPS 反向代理。只有显式 `--public-url` 才允许非回环监听；这不是内置 TLS 开关，TLS 必须由隧道或反向代理终止。

反向代理应保留原始 Host，关闭 SSE 缓冲和缓存，并允许长连接，例如 Nginx location：

```nginx
location / {
    proxy_pass http://127.0.0.1:4141;
    proxy_set_header Host $http_host;
    proxy_http_version 1.1;
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 3600s;
}
```

程序按显式 origin 校验 Host / Origin，不依赖未经验证的 `X-Forwarded-*`，不开放任意 CORS。公开访问使用 Secure、HttpOnly、SameSite Cookie；本机回环 HTTP 使用本机 Cookie。会话令牌不放在 URL 或 localStorage。

密码使用 Argon2id；更改密码会撤销全部设备会话。注销会切断该设备受保护的事件订阅，但不会取消正在执行的任务。任务必须显式点击停止。

### Computer Use：KDE Plasma Wayland

固定 `computer` 工具按 **浏览器 DOM → 原生可访问性树 → 图像/坐标** 优先级工作，不需要插件、MCP、ChromeDriver 或 Node 运行时。

1. **DOM 浏览器**：启动自己的 headless Chrome/Chromium、独立 profile 和 CDP 连接，不扫描或接管用户已有浏览器。支持 open、observe、ref click/fill、type/key/scroll 和真实 PNG 截图。页面快捷键用 `key`：裸 `B`/`b` 发 key=b、code=KeyB、不隐式 Shift；`Shift+B` 才发大写与 Shift，`Ctrl+B`、数字和 ASCII 标点也支持，事件为真实 keydown/keyup。`type` 只往当前可编辑控件输入文本，非编辑焦点会明确拒绝，不能拿它替代全局快捷键。引用绑定当前页面/节点身份；导航、重新观察或语义变更后，旧引用会被拒绝。坐标点击需要新截图，且截图会被消费，不能盲目重复。
2. **独立原生桌面**：KWin `--virtual`，独立 Wayland socket、D-Bus、runtime、HOME/config/cache；应用在该桌面运行，不争用宿主鼠标焦点。固定 Python GI AT-SPI 桥只观察本工具启动的应用和后代，优先 Action/EditableText；不支持语义树的界面可使用 KDE FakeInput + Screenshot2 像素闭环。支持 Unicode 输入。该图形隔离不是文件/网络安全沙箱。
3. **必要时宿主接管**：工具显式选择 `target=host`，不自动从 DOM 失败降级到宿主。已按用户授权默认允许备用路径，GUI 可关闭。注入前必须获得短时会话租约，实际物理输入监测健康，且用户至少空闲 1.5 秒；人工输入、关闭开关、过期或急停会取消后续输入并释放按键。只汇报活动时序，不记录按键内容。每次宿主输入都需要 10 秒内的新截图。坐标后端当前仅接受单屏、原点 0/0、scale=1、正常旋转且截图尺寸匹配的输出；其它布局明确拒绝误点，键盘操作不依赖该坐标映射。

聊天中的计算机图标可以查看实际依赖、root 通道、占用、最近截图，并全局紧急停止。状态查询不会偷偷启动浏览器、KWin 或输入监测。截图按会话鉴权，不暴露文件路径或模型凭据；真实像素附入视觉模型请求，纯文本模型不能冒充看过截图。独立浏览器启动时明确使用应用的手动／环境／直连代理配置，DevTools 回环连接始终直连且不带模型凭据；浏览器运行中修改代理会要求先停止再打开，而不是悄悄切路。Chrome 的代理 URL 凭据认证不受本版支持，会明确拒绝，不回退直连。

**环境要求：** KDE Plasma/KWin 6.8 Wayland（私有协议需版本探测）、Chrome/Chromium、`dbus-run-session`、Python 3 + PyGObject/GI + Atspi（原生桥）、`at-spi2-registryd`、`prlimit`；本机已具备并实际测试。原生测试夹具另需 GI Gtk3。宿主活动监测在需要时使用 root/免密 sudo 读取物理 evdev，仅时序，不 grab 设备。不修改全局 KWin 插件、快捷键或系统桌面配置。

权限与控制范围是两件事：本机已实际验证 `sudo -n id -u` 为 0，但不宣称 root 会让锁屏、登录管理器、受保护表面、所有跨域 iframe 或任意应用自动具备可控 DOM/可访问性树。主 frame 和 open shadow roots 已支持，跨域 iframe 需后续 frame-session 扩展。原生私有桌面面向 Wayland 应用；X11-only 应用可用明确的宿主备用路径，但本版不在私有桌面自动启动 Xwayland。宿主接管有物理事件到达/注入在途的竞态，不能承诺数学意义上的零争用；严格不抢输入时使用前两条隔离路径。

真实验收只操作本工具新建的浏览器和虚拟桌面，没有向用户宿主界面注入测试点击、按键或截取其私密窗口。

### 自动压缩与继续执行

模型请求前检查上下文预算。空间不足时，执行器进入 `auto_compacting`，在不存在未结算工具调用的边界生成摘要，再使用新上下文继续同一任务，而不是将压缩当成完成。全文过大时按 UTF-8 安全块逐步合并摘要；整个过程成功且新上下文确实能容纳下一请求，才原子切换 epoch。中途失败/取消保留原始上下文并停止，避免无限压缩循环。摘要明确保留当前任务、下一步、待答问题和未完成 GOAL。

压缩会产生模型费用，并可能重建部分提示缓存。极小上下文窗口或单个任务状态本身过大时，仍会明确停止并要求调整模型配置，而不是静默丢失任务。

### 稳定前缀与缓存排障

正常请求保持固定 instructions/tools，旧 native 响应（reasoning、phase、工具调用原参数字符串）不改写，只追加新项目。父会话与子 agent 默认共用 `justai:v1:<主会话ID>` 的稳定 `prompt_cache_key`，不使用每轮 UUID。该标识只辅助符合协议的服务端路由，不保证缓存命中；未强行添加模型专用 TTL 或付费缓存写入参数。

本地 `request_audit` 事件只记录 HMAC/计数，验证上次 input + 全部 output 是否构成下一请求的完整前缀，并区分固定设置变化、旧历史变化、native 回放变化和压缩换 epoch。完整请求哈希随尾部追加而变化是正常现象，不应因此声称缓存被重置。`usage.upstream_usage` 保留数值详情，`cached_tokens_present=false` 表示上游未给该字段，不能当作 0%。没有缓存率面板；未额外落盘原始请求、密钥或推理密文，原始会话仍按既有明文约定保存。

2026-11-14 的真实会话核验与两次极短往返结果见 [缓存请求检查](CACHE_INVESTIGATION.md)。历史事件没有逐包指纹的部分无法事后证明供应商内部缓存路径，不能仅凭截图归责任一方。

### 问题栈

AI 遇到歧义可调用固定 `ask_user`：

- **阻塞问题**：暂停该会话后续模型请求和工具执行，包括同一响应中剩余工具；用户回答前不会继续。页面关闭不算回答。
- **非阻塞问题**：问题保留在栈中，AI 可继续工作；用户可以稍后回答，AI 也可撤回已不再需要的待答非阻塞问题。
- 问题可带建议选项，也可自由输入。回答先持久化到 inbox，在工具调用/结果完整闭合的边界一次性入模。迟到回答可唤醒已空闲会话，相同回答重试不会重复驱动。
- 阻塞问题不能被 AI 静默撤回。回答和撤回历史保留，重启后问题不丢失。

### 长任务 GOAL 列表

聊天中的长期目标列表支持新增标题和目标、开始、暂停、恢复、取消，展示进度、执行轮数与完成状态。新增默认为待开始，不自动花费 token；每会话同时最多一个 active 目标。

激活后，普通回复结束**不会结束目标**：执行器会持续提醒目标并继续下一轮，直到 AI 使用 `goal complete` 提交明确的完成证据，或用户暂停/停止/取消。AI 可以更新进度、拆出待开始目标，但不能把“说了一段回答”当成完成。

没有固定总轮数上限，运行可能持续产生费用。用户停止会暂停 active GOAL；网络/协议/摘要等不可恢复错误会暂停目标，避免错误请求无限循环。重启将 active GOAL 改为 paused，需要用户恢复；不会在开机后悄悄继续执行本机操作。

### 联网搜索与网页读取

`web_search` 和 `web_fetch` 是 Rust 程序内置工具，始终经过相同的明确代理/TLS/超时策略，不会附带模型 API Key 或浏览器 Cookie，也不需要模型供应商提供托管搜索功能。

设置 → 网络与诊断可以选择固定的搜索来源：

- **DuckDuckGo**：默认公共 Lite 搜索，不需要 Key。公共 IP 可能限流或出现验证码，遇到时如实返回错误，不绕过验证码，也不偷偷切换来源。
- **Brave**：使用单独配置的搜索 API Key，不复用模型密钥；可以明确配置可信的兼容 API 地址。
- **SearXNG**：填写自己选择的实例地址，该实例必须启用 JSON 搜索。

搜索返回精简标题、URL 和摘要，网页读取返回正文与链接；HTML 作为不可信数据处理，不执行 JavaScript，因此不能读取必须登录或完全依赖客户端脚本的网页。下载上限 2 MiB、最多显式跟随 3 次匿名重定向，工具输出入模前有限长。

Codex 的联网不等同于本机 Chrome：官方既有 [Responses 托管 `web_search`](https://developers.openai.com/api/docs/guides/tools-web-search)，当前源码也有独立 [`web.run` / 服务端 SearchClient](https://github.com/openai/codex/blob/main/codex-rs/ext/web-search/src/tool.rs)。这些属于供应商端搜索路径，不保证任意中转站支持。本项目不调用 Codex 私有接口，而是使用本地 HTTP 客户端与明确的搜索来源。

### AI 主动读取图片

模型可自行调用 `read_image` 查看本地 PNG/JPEG/GIF/WebP，不必由用户上传。后端实际解码图片、校验大小，并把图片像素作为 `input_image` 放进下一次 Responses 请求；绝不凭文件名生成所谓的图片描述。

需要选中的模型声明并实际支持图片。纯文本模型会收到明确的工具错误。原文件上限 10 MiB，解码有内存和尺寸预算，大图最长边归一化到 2048 像素，GIF 读取首帧；SVG 可在浏览器预览，但 AI 图片工具要求先将其渲染为栅格图。工具结果与图像上下文在同一事务提交，本地日志仍为可读明文。

### 文件树与预览

聊天右侧为真实工作目录的按需文件树，显示正在编辑、本轮新建和修改状态；手机通过文件图标打开。内置写入/编辑有即时状态，bash 或外部程序的文件变化也由 Linux watcher 捕获。每个用户回合结束附上已确认的新建/修改/删除文件列表，不依赖模型是否在答案中列出路径。

点击 HTML、SVG、PNG/JPEG/WebP/GIF 可在新标签页预览，代码和普通文本以明文显示。所有文件接口仍需登录。HTML/SVG 使用强制 CSP sandbox、独立不透明文档 origin、禁止脚本/网络/表单，避免生成内容控制 agent；因此这是安全静态预览，不是任意网站应用托管。预览只允许工作目录内的普通文件，拒绝越界、符号链接与特殊文件，单文件上限 32 MiB。

文件树默认忽略 `.git`、`node_modules`、`target`、私有运行目录等；超出遍历上限会明确报错，而不是伪造完整结果。

### 明文会话与崩溃恢复

SQLite 原本就不加密，仍使用 WAL、FULL 同步和专用数据库线程。另自动维护 `DATA_DIR/sessions/<session-id>.jsonl` 明文日志，无需应用密钥或解密工具即可读取，适合跨 agent 分析。首行为 `{"type":"session","schema_version":1,"session":{...}}`，后续每行是带全局 `seq` 的原始用户/回复/工具/文件等事件。`context_note` 补充继承上下文及子任务报告；`session_settings` 记录路由变化。也可通过已登录的 `/api/sessions/<id>/export` 下载 JSONL。

上游可能提供不可解读的加密推理，它不是本地会话加密：原始协议状态仅为同路由回放保留，明文 JSONL 不输出该 opaque ciphertext，但用户消息、可见回复、工具参数和结果都可直接阅读。日志不会自动注入站点密钥。文件权限仍为 0600、目录 0700；这是本机访问控制，不是加密。

用户消息带幂等 ID；工具执行意图和执行结果落盘；网页断线不取消运行，SSE 按递增序号补放。JSONL 镜像以数据库为权威，启动时可以重建。

任意 bash 副作用无法实现真正的 exactly-once：如果命令产生副作用后程序崩溃、结果还没提交，重启会将其标记为 **unknown**，向上下文说明不确定性，**不会自动重跑**。

原始历史在自动或手动压缩后仍保留；压缩创建新的上下文 epoch。后台任务完整日志保存在私有数据目录。该程序没有沙箱，拥有同用户权限的进程或 AI 仍能读取本机同用户文件；数据库文件权限不是对全权限 agent 的隔离保证。

## 设计

- 单进程：Axum + Tokio + reqwest/rustls + rusqlite。
- SQLite worker 是唯一持久化入口，不在异步线程直接执行阻塞数据库操作。
- 每会话一个执行器；子 agent 独立会话与取消令牌。
- 静态 ToolRegistry，无动态代码加载。
- Responses 输入保留完整的可重放项目和顺序；UI 事件不等于模型上下文。
- React/Vite 构建结果通过 rust-embed 编译进最终二进制。

私有测试凭据、浏览器测试产物和运行数据不属于源码，禁止提交。
